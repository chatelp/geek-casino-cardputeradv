# Images de publication

Générées par `python3 scripts/make_store_images.py`, depuis les mêmes
sources que l'appareil : la fonte 5×7 et l'invader viennent de
`design/tools/art_*.py`, les écrans de `captures/screens`, le GIF de
`captures/gif` (mode `--frames`).

| Fichier | Contenu |
|---|---|
| `01-cover.png` | **La cover M5Burner** (1200 × 900) — le nom, l'invader, la règle |
| `02-mosaic.png` | Mosaïque 3×2 d'écrans réels — pour les posts |
| `../images/spin.gif` | Un tour complet animé, gain compris — pour les posts |

Une seule cover part sur M5Burner : la boîte du catalogue divise les
carrousels en vignettes illisibles. Les écrans sont agrandis à facteur
entier depuis le 240 × 135 natif — à tout autre facteur, les pixels
bavent.
